Sistema de Monitoramento IoT com ESP32, MQTT e Node-RED

Projeto de Internet das Coisas (IoT) desenvolvido para integrar sensores, comunicação MQTT, visualização de dados e notificações automatizadas por e-mail.

O sistema utiliza um ESP32 simulado no Wokwi para adquirir informações de sensores e integrá-las a um fluxo de monitoramento desenvolvido no Node-RED.

🎯 Objetivo

Explorar a integração entre microcontroladores, protocolos de comunicação e ferramentas de automação para desenvolver uma solução de monitoramento IoT.

🛠️ Tecnologias utilizadas

- ESP32: microcontrolador utilizado na simulação.
- Wokwi: ambiente de simulação do circuito eletrônico.
- MQTT: protocolo de comunicação para troca de mensagens.
- Node-RED: desenvolvimento dos fluxos de processamento e automação.
- Dashboard Node-RED: interface para visualização dos dados.
- E-mail: envio de notificações automatizadas.

📡 Sensores utilizados

- DHT22: medição de temperatura e umidade.
- LDR: detecção de variações na luminosidade.
- HC-SR04: medição de distância por ultrassom.

⚙️ Funcionalidades

- Aquisição de dados dos sensores pelo ESP32 simulado.
- Comunicação entre os componentes utilizando MQTT.
- Integração e processamento dos dados no Node-RED.
- Visualização das informações em um dashboard.
- Envio de notificações automatizadas por e-mail.

🧠 Conhecimentos aplicados

- Internet das Coisas (IoT).
- Sistemas embarcados e microcontroladores.
- Comunicação entre dispositivos utilizando MQTT.
- Integração de sistemas com Node-RED.
- Monitoramento de sensores e automação de processos.

🚧 Status do projeto

Funcionalidades principais implementadas e testadas no ambiente de simulação.
